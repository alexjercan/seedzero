Pull slowly or jerk it. Which string snaps? A string above the ball, one below. Each snaps at twenty newtons, twice the ball's weight. On top, the hand pulls slowly. Both stretch, but the top one also carries the ball, so it snaps first, and the ball drops. Below, the hand jerks. The bottom string stretches before the ball can follow, and snaps. The ball stays.
Pull slowly or jerk it. Which string snaps? Pull slowly, and the top string snaps after a fifth of a second. Jerk it, and the bottom string snaps in five thousandths of a second, before the ball has moved a tenth of a millimeter.
